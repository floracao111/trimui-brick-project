Stretch a Sketch

Move: WASD or the arrow keys (press two for a diagonal), or either stick in any direction. First, move to where you want to start and press Space (or button X) to put the pen down. After that it is one continuous line, like the toy, and you can't lift it. Send: Enter (or button A). Clear and pick a new start: Backspace (or button B). Color scheme: C (or button Y) cycles through them.
